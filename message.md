### Pregunta 10

* **Pregunta:** El proceso de análisis de datos sigue una serie de etapas ordenadas. (Completar los espacios)
* **Respuesta correcta:** 
  > El proceso de análisis de datos sigue una serie de etapas ordenadas. Primero se realiza la **[Recolección de los datos]**, donde se obtienen los datos desde distintas fuentes. Luego se procede al **[Almacenamiento]**, permitiendo guardar y organizar la información recopilada. La siguiente etapa es la **[Limpieza y preprocesamiento de datos]**, necesaria para corregir errores, eliminar inconsistencias y preparar los datos para su uso. Después se lleva a cabo el **[Análisis]**, donde se interpretan los datos para obtener información útil. Finalmente se realiza la **[Visualización y/o modelado]**, presentando los resultados mediante gráficos, reportes o modelos.

### Pregunta 13

* **Pregunta:** A partir del gráfico mostrado (gráfico de barras de "Lenguajes preferidos por estudiantes"), indicar cuáles de las siguientes afirmaciones son correctas.
* **Opciones:**
  * A. Java y JavaScript juntos representan menos de la mitad del total de estudiantes
  * B. Entre Java y C++ reúnen la misma cantidad de estudiantes que Python y JavaScript juntos
